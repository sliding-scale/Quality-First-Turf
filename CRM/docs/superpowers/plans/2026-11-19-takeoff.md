# Material takeoff (PRD 4.2) Implementation Plan

> Built in the session (the user chose to build here). Pure rules and backend rules get a failing test first.

**Goal:** A project in Preplanning has a Takeoff tab: the measurements go in, the materials list works out how much of each to order from the business's own formulas, with supplier, stock and lead time, and a requirements summary comes out.

**Spec:** PRD 4.2 ("calculation rules must be configurable using the product catalogue and formulas supplied by the client"), CRM rule 8 (formulas are data, a safe parser, never eval).

## Global constraints
- Dev only; no deploy without the user's go-ahead; no commits unless asked. Additive schema. Every function starts with `requireModule` / `requireProject` (the Preplanning pipeline module). Costs show only with the "Show pricing" module. Skeletons, hover feedback, red-on-submit, motion, 400 px.

## My calls (D-091, the client's catalogue and formulas are still to come)
- **Everything is editable data, nothing is seeded:** the Materials list (Settings > Materials) starts empty and the team or the client's list fills it; each material has its own formula, wastage % and rounding. The formula editor tries the formula on sample measurements as you type.
- **Standard measurements** a formula can use: area, perimeter, depth, length, width, height, quantity. Functions: ceil, floor, round, abs, sqrt, min, max.
- **A takeoff line is a labelled snapshot** of its material (name, unit, formula, supplier, cost, lead time, stock) so a later change to the catalogue never changes a takeoff already made; "Refresh from material" re-reads it. The quantity to order is the worked-out one unless the person types their own.
- **Measurements start from the visit** when the project came from the customer form (the sum of its work areas), and stay editable.

## Tasks
1. Pure rules `convex/crm/lib/formula.ts` and `lib/takeoff.ts` with tests (done first).
2. Tables `materials`, `takeoffs`, `takeoffLines`; `convex/crm/materials.ts`; `convex/crm/takeoff.ts` (`get`, `saveInputs`, `addLine`, `updateLine`, `refreshLine`, `removeLine`). Tests.
3. Screens: Settings > Materials (list, edit dialog with formula tester), the project's Takeoff tab (measurements, lines, summary, print and CSV).
4. Docs, the whole check, deploy reminder.
