# Quotes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the quote builder, sending (secure link), the client's public approval page, revisions and the Closed Won signature rule (PRD 3.6, 3.3).

**Architecture:** Additive backend in `convex/crm/` on the existing `quotes`, `quoteLineItems`, `quoteNotes` tables plus `quoteEvents`, `quoteRevisions`, `quoteAttachments`. Pure money rules in `convex/crm/lib/quoteMath.ts`. Staff screens extend `/quotes`; the client's page is public at `/q/[token]` (open in `proxy.ts`), checked only by a secret token. Pipeline stage changes caused by a quote use one helper with a system actor.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` first), React 19, Convex (read `convex/_generated/ai/guidelines.md` first), convex-test + vitest.

**Spec:** `CRM/docs/superpowers/specs/2026-11-10-quotes-design.md`, with the user's answers of 2026-11-11 (below). Also read `CRM/CLAUDE.md`, repo-root `CLAUDE.md`, `convex/crm/quotes.ts`, `convex/crm/pipeline.ts`, `CRM/components/quote-page.tsx`.

## User's answers (2026-11-11, binding)
1. Sending from the CRM is put off (Zoho services will be connected together later): **Send creates the secure link, marks Awaiting response, and shows the link to copy**; no email or text is delivered.
2. The on-screen signature on the public page is the approval method. Staff can also collect it on a device ("Collect Signature"). **A deposit received can optionally carry an uploaded PDF or image as proof.**
3. Staff close a project as won once the quote is approved and signed (and any deposit received). **Nobody, not even an Admin, can mark Closed Won without the signature.** The refusal is an error that, for an Admin, offers "Open the quote" so they can collect the signature at once.

## Global Constraints
- Dev deployment only; never `npx convex deploy` or `--prod`. Additive schema only (optional fields, new tables, a wider union). Forms tables and `convex/projects|sales|jobber` untouched. New files in `convex/crm/`, names letters, digits, underscores, periods.
- Every staff function starts with `requireBusiness` or `requireEditor`; Project Managers read only. Public functions take a `token` and check it; they never return staff data, other quotes, or notes.
- Money in whole cents; rounding `Math.round`; business time zone America/Los_Angeles; queries do not read the clock.
- Statuses: `Draft`, `Awaiting response`, `Changes requested`, `Approved`, `Rejected` (new), `Converted`, `Archived`. "Viewed" is `viewedAt`, never a status.
- Closed Won guard (replaces the Admin-only rule in `checkMove`/`applyMove`): the project must have an **Approved quote that has a signature**, and if that quote's deposit is more than 0, the deposit must be marked received. Failure throws `ConvexError({ code: "needs_signature" | "needs_deposit", message, quoteId? })`. Reopening a closed project stays Admin only.
- UI rules (`CRM/CLAUDE.md`): skeleton per screen; hover and press feedback; fixed table columns; red invalid fields on submit; smooth motion with exit animations; unbuilt controls greyed `disabled`; tooltips via `data-tip`; **mobile responsive: every new screen is checked at 400px** (no horizontal page scroll, no squeezed controls, touch targets at least 40px, sticky action bars on phones).
- Out of scope: email or text delivery, Convert to Job (greyed), Reviews and Add Field (greyed), payments.
- No commits unless the user asks.

## Review Focus
- A client link that is wrong, expired (quote archived or deleted) or for another quote shows a plain "link not valid" page and leaks nothing.
- Approving twice, or approving a quote that is no longer awaiting response, is refused.
- Optional lines the client unticks change the total the client approves; the approved total is stored.
- A quote edited after sending cannot silently change what the client sees: staff must Resubmit.
- Discount larger than the subtotal never makes a negative total; tax and deposit follow the discounted total.
- Closed Won with no signature fails for an Admin too, with the quote id in the error.
- A signature image must be an image, with a size limit; a deposit proof must be a PDF or image, with a size limit.
