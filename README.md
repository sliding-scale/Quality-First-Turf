# Quality First Turf

Monorepo for the Quality First Turf projects. Each app is self-contained, with its own dependencies, env files and tooling. Run commands from inside the app folder.

| Folder | What it is |
| --- | --- |
| [`forms/`](forms) | The **live** customer-intake and on-site-visit app (Next.js, Convex, Jobber push). Has its own `CLAUDE.md` with handoff rules. |
| [`CRM/`](CRM) | The CRM that will replace Jobber. Docs and mockups so far; no code scaffolded yet. |
